Create a Lean 4 project and prove the five theorems below in `TuringTask/Basic.lean`. This is a proof-writing task.

Mathematical statement. $F_n$ are the Fibonacci numbers ($F_0 = 0$, $F_1 = 1$, $F_{n+2} = F_{n+1} + F_n$; `Nat.fib n` in Mathlib) and $L_n = F_{n-1} + F_{n+1}$ for $n \ge 1$ are the Lucas numbers ($L_1 = 1$, $L_2 = 3$, $L_3 = 4$, $L_4 = 7$, ...). All letters denote natural numbers.

1. If $F_n$ is a perfect square, then $n \in \{0, 1, 2, 12\}$.
2. If $n \ge 1$ and $L_n$ is a perfect square, then $n \in \{1, 3\}$.
3. If $F_n$ is twice a perfect square, then $n \in \{0, 3, 6\}$.
4. If $n \ge 1$ and $L_n$ is twice a perfect square, then $n = 6$.
5. If $F_n$ is a power of $2$, then $n \in \{1, 2, 3, 6\}$.

Lean statement. The file `TuringTask/Basic.lean` must contain the five theorems, stated exactly as below, with each `sorry` replaced by a complete proof:

```lean

namespace TuringTask

theorem fib_eq_sq (n x : Nat) (h : Nat.fib n = x ^ 2) :
    n = 0 \/ n = 1 \/ n = 2 \/ n = 12 := by
  sorry

    n = 1 \/ n = 3 := by
  sorry

theorem fib_eq_two_mul_sq (n x : Nat) (h : Nat.fib n = 2 * x ^ 2) :
    n = 0 \/ n = 3 \/ n = 6 := by
  sorry

theorem lucas_eq_two_mul_sq (n x : Nat) (hn : 1 <= n)
    (h : Nat.fib (n - 1) + Nat.fib (n + 1) = 2 * x ^ 2) :
    n = 6 := by
  sorry

theorem fib_eq_two_pow (n k : Nat) (h : Nat.fib n = 2 ^ k) :
    n = 1 \/ n = 2 \/ n = 3 \/ n = 6 := by
  sorry

end TuringTask
```
