Create a Lean 4 project and prove the five theorems below in `TuringTask/Basic.lean`. This is a proof-writing task.

Mathematical statement. $F_n$ are the Fibonacci numbers ($F_0 = 0$, $F_1 = 1$, $F_{n+2} = F_{n+1} + F_n$; `Nat.fib n` in Mathlib) and $L_n = F_{n-1} + F_{n+1}$ for $n \ge 1$ are the Lucas numbers. All letters denote natural numbers.

1. If $n \ge 3$ and $n \ne 6, 12$, there is a prime $q$ that divides $F_n$ but divides none of $F_1, \dots, F_{n-1}$.
2. If $n \ge 2$ and $n \ne 6$, there is a prime $q$ that divides $L_n$ but divides none of $L_1, \dots, L_{n-1}$.
3. If $n \ge 1$, then the number of divisors of $n$ is at most $4$ plus the number of distinct prime factors of $F_n$.
4. If $3 \le m < n$ and $F_m$ and $F_n$ have the same prime factors, then $m = 3$ and $n = 6$.
5. If $n \ge 3$ and $n \ne 5, 6, 12$, then $F_n$ has a prime factor $q$ with $q \equiv 1$ or $q \equiv -1 \pmod n$.

Lean statement. `x % q = 0` means that $q$ divides $x$, and `q % n = n - 1` means $q \equiv -1 \pmod n$. The file `TuringTask/Basic.lean` must contain the five theorems, stated exactly as below, with each `sorry` replaced by a complete proof:

namespace TuringTask

theorem exists_prime_fib (n : Nat) (hn : 3 <= n) (h6 : Not (n = 6)) (h12 : Not (n = 12)) :
    exists q : Nat, q.Prime /\ Nat.fib n % q = 0 /\
      forall k : Nat, 1 <= k -> k < n -> Not (Nat.fib k % q = 0) := by
  sorry

      forall k : Nat, 1 <= k -> k < n -> Not ((Nat.fib (k - 1) + Nat.fib (k + 1)) % q = 0) := by
  sorry

theorem card_divisors_le (n : Nat) (hn : 1 <= n) :
    n.divisors.card <= (Nat.fib n).primeFactors.card + 4 := by
  sorry

theorem primeFactors_fib_eq (m n : Nat) (hm : 3 <= m) (hmn : m < n)
    (h : (Nat.fib m).primeFactors = (Nat.fib n).primeFactors) :
    m = 3 /\ n = 6 := by
  sorry

theorem exists_prime_fib_mod (n : Nat) (hn : 3 <= n) (h5 : Not (n = 5)) (h6 : Not (n = 6))

    exists q : Nat, q.Prime /\ Nat.fib n % q = 0 /\ (q % n = 1 \/ q % n = n - 1) := by
